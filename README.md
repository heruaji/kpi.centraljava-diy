# KPI Central Java - DIY

Web application untuk Control Tower KPI Central Java - DIY.

## Baseline
- React + TypeScript + Vite
- Responsive App Shell
- Desktop sidebar expanded/collapsed
- Mobile off-canvas navigation
- Single global period selector
- Region Control Tower shell

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Tahap berikutnya: calculation engine, data adapter Spreadsheet/Worker, Area Control Tower, Branch Command Center, dan KPI Detail.
